# SLZB · 私人账户观察室

**管理员配置账户，朋友用自己的用户名和密码登录，只读查看被分配给他的资产。**

支持多个查看用户及多个 Binance 现货账户。每个用户绑定一个交易所账户；同一账户也可以分配给多个用户。用户页面只有账户总览、资产持仓和交易记录，没有 API 配置、用户管理或交易入口。

## 本地预览

需要 Node.js **24.x**。

```bash
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。尚未配置自建账号时，演示用户名 **demo**，密码 **demo123456**。演示仅有模拟数据；创建自己的配置后默认演示账号自动停用。

## 你如何配置（管理员）

在项目目录执行：

```bash
npm run setup
```

按菜单依次操作：

1. **新增交易所账户 / API**：填写账户名称、Binance 只读 API Key / Secret、主网或 Testnet、监控交易对。也可先选模拟数据测试。
2. **新增查看用户并绑定账户**：设置朋友的用户名和密码，选择他可以查看的账户。
3. 本地首次配置后重启 `npm run dev`。朋友只需要网址、自己的用户名和密码。

继续运行同一命令可以新增其他朋友、修改 API、维护盈亏口径、改密码、重新绑定账户、停用用户或撤销其全部登录。

配置写入 `.slzb/accounts.json`，密码只保存 scrypt 哈希；API 密钥留在服务端私密配置中。首次设置会自动生成 `.env.local` 中的 `SESSION_SECRET`。这两个位置均被 Git 忽略。

**完整管理员操作说明：[docs/ADMIN.md](docs/ADMIN.md)。**

## 部署到 Vercel

1. Vercel 导入 `SiaoKiasu/SLZB`，选择 Next.js 和 Node.js 24.x。
2. 在本地管理好账户与用户后执行 `npm run config:export`。
3. 在 Vercel Environment Variables 设置：

| 变量                 | 填什么                                       |
| -------------------- | -------------------------------------------- |
| `PORTAL_CONFIG_JSON` | `.slzb/vercel-config.json` 的完整内容        |
| `SESSION_SECRET`     | `.slzb/session-secret.txt` 的完整内容        |
| `DATABASE_URL`       | 可选：Neon Postgres 连接字符串，用于保存净值 |
| `CRON_SECRET`        | 可选：至少 32 位随机值，用于后台采集         |

4. 点击 Redeploy。后续增加用户或修改 API 后，重新导出、更新 `PORTAL_CONFIG_JSON` 并 Redeploy；保持 `SESSION_SECRET` 不变可保留未被修改用户的登录。
5. 把部署网址及各自的用户名、密码发给朋友。**不需要把配置文件或 API 信息交给他们。**

默认函数区为 Frankfurt (`fra1`)。交易所访问仍受账户适用地区及出口 IP 限制；启用严格 IP 白名单时需要固定出口方案。项目不会绕过交易所访问限制。

## 登录状态

- 使用一年有效期的持久化 HttpOnly Cookie，活跃请求自动续期，不再每 12 小时退出。
- 刷新页面、关闭页面或重启浏览器后，只要 Cookie 仍保留即可继续查看。
- 主动退出、清除浏览器 Cookie、长期一年未访问、管理员修改密码/绑定、撤销登录或停用用户后，需要重新登录。
- 用户每次请求都重新校验当前权限。停用/撤销配置生效后，下次请求即拒绝访问。
- 同一浏览器的多个标签页会同步登录/退出状态；不同查看账号应使用各自浏览器资料或设备。

## 已实现

- 中文电脑/手机 Portal，密码登录，按用户隔离账户。
- 现货估值、可用与冻结余额、资产分布、成本浮盈亏和配置本金口径的累计盈亏。
- 各监控交易对最近 100 笔成交，筛选、分页、CSV 导出，以及全现货钱包当前挂单。
- 页面可见时每 60 秒自动刷新，手动刷新，缺失/过期数据提示。
- 可选持久净值，24h / 7d / 30d / 90d 曲线。Vercel 每日 Cron 为启用的真实账户保存快照。
- 账户接口只读，没有下单、撤单、提现或转账功能。

## 盈亏口径

由管理员通过配置工具维护。累计盈亏 = 当前净值 − 起始净值 − 期间净入金；持仓浮盈亏 = 持有数量 ×（当前价格 − 剩余持仓平均成本）。成本和净入金目前不是自动对账，发生交易或转账后需要管理员更新。没有完整口径时显示缺数据，不当成零。

报价为 USDT；除 USDT 计价基准外，稳定币也按市场价格估值。未知行情资产保留在列表、不计入小计，并暂停全账户累计盈亏及快照写入。24h 行情涨跌和净值曲线都不等同于资金流调整后的收益率。

目前只支持 Binance Spot 钱包，不含理财、资金账户、合约、自动全历史成本、已实现盈亏或充值/提现/内部划转账本。
