# 管理员操作指南

## 初始化

运行 `npm run admin:setup`，按提示设置固定管理员。生成的 `.slzb/admin-env.txt` 是私密文件，不提交 Git，不发给查看用户。

| 环境变量              | 用途                                         |
| --------------------- | -------------------------------------------- |
| ADMIN_USERNAME        | 固定管理员用户名                             |
| ADMIN_PASSWORD_HASH   | scrypt 密码哈希（初始化命令生成）            |
| SESSION_SECRET        | 会话签名密钥                                 |
| CONFIG_ENCRYPTION_KEY | 账户目录 AES-256-GCM 加密密钥，64 位十六进制 |
| DATABASE_URL          | Neon Postgres 连接地址，Vercel 必填          |
| ADMIN_DISPLAY_NAME    | 可选，管理员显示名称                         |
| CRON_SECRET           | 可选，定时净值采集鉴权                       |

在 Vercel 配好这些值后 Redeploy 一次。后续日常管理不涉及环境变量。生产和 Preview 使用不同数据库及密钥，避免测试修改生产账户。

管理员用户名及密码哈希是环境配置的固定身份，网页不能删除、停用或修改它，也不能创建第二个管理员。修改管理员凭据需更新对应环境变量并部署；旧管理员登录状态随哈希变化失效。其他服务密钥不需要跟着改。不要随意更换 CONFIG_ENCRYPTION_KEY；否则数据库内目录无法读取。

初始化命令只生成文件，不直接修改本地环境或云端。它再次运行时保留已生成的会话与加密密钥。若导出文件来自另一部署，请使用该部署已有密钥，不要混用。

## 日常管理

1. 管理后台 → 交易所账户 → 新增账户：名称、唯一 ID、Binance 主网/测试网、只读 API Key/Secret、本金。可先建演示账户测试。
2. 管理后台 → 用户管理 → 新增用户：用户名、密码、显示名称、绑定账户。每个查看用户绑定一个账户，同一账户可以绑定多人。
3. 编辑用户：重置密码（留空保留）、改绑账户、允许或禁止登录。任何保存均撤销此用户旧登录。
4. 撤销登录：让用户所有设备重新登录，密码不变。删除用户也立即收回访问权。
5. 编辑账户：改名称、API、本金或停用。账户 ID、数据来源和网络固定；需要变更时新建账户。API 留空保留旧值，替换时必须同时输入 Key 和 Secret。密钥保存后不回显。
6. 点击账户行的「查看」进入该账户数据；点击「成本」维护每币单位成本。所有绑定用户共享这套手工成本。

管理员可以管理全部账户配置，包括停用账户。停用账户不调用交易所数据；可重新启用后查看。停用账户会撤销绑定用户已有登录。普通用户看不到后台入口，访问管理 API 返回 403，伪造 accountId 也只能读取自己的账户。

「操作记录」保留最近 100 次用户及账户修改；只记录操作者、时间、操作与对象，不记录明文密码或 API。成本有独立修改记录。并发修改用 revision 校验，出现冲突请重新加载再编辑。

## 存储与迁移

云端使用 Neon：目录表 `linden_directory` 存放加密账户和用户目录；密码额外使用带随机盐的 scrypt 哈希。数据库包含的普通用户始终是 viewer，固定管理员不写入数据库。成本、成交进度、净值继续使用各自的数据表。

本地没有 DATABASE_URL 时使用私密 `.slzb/directory.enc`。Vercel 不允许用本地临时文件代替数据库，以免重启或重新部署后丢失用户。新目录从空状态开始，旧配置文件保留但不自动导入；可直接从后台重新建立用户和账户。

如果需要复用原来的数据库成本或历史，请保持账户 ID、网络和 API Key 不变（存储按这些值隔离）。更换 Key 会进入新的存储范围，需要重新录入成本；不会将旧 Key 的记录误当作新账户历史。

`.env.local` 使用 dotenv：密码哈希的 `$` 必须写成 `\$`；在 Vercel 控制台填写时则使用原始 `$`。所有环境变量均为服务端变量，不能添加 `NEXT_PUBLIC_`。

## 常见问题

- 管理员环境变量配置不完整：检查用户名、哈希与 SESSION_SECRET。
- 管理后台需要 DATABASE_URL：为 Vercel 项目连接 Neon，并设置连接地址。
- 账户配置无法读取：检查数据库连接及原来的 CONFIG_ENCRYPTION_KEY，不要用新密钥覆盖旧配置。
- 用户无法登录：确认用户和绑定账户均启用，用户名和密码正确。
- 登录限流为每服务实例 15 分钟 8 次失败尝试；公开部署可对 `/api/session` 配置平台全局限流。
